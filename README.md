# Annaelle Sales Manager

Автономный лендинг вакансии менеджера отдела продаж Annaelle.

## Файлы

- `index.html` - лендинг для GitHub Pages.
- `tilda-t123.html` - полный код для HTML-блока T123 в Tilda.
- `assets/` - локальные изображения и брендовые SVG.

## Публикация

GitHub Pages публикует ветку `main` из корня репозитория.

После публикации вставьте содержимое `tilda-t123.html` в отдельный блок T123 на странице Tilda. В блоке уже настроены:

- автоматическая высота iframe;
- якорные переходы;
- мобильная плавающая кнопка;
- Meta Pixel `27765618759737126`;
- событие `Lead` при отправке анкеты.
